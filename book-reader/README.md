# 📖 קורא ספרים — הקראת ספר דיגיטלי

אפליקציה בקובץ HTML יחיד (`index.html`) שפותחת ספר דיגיטלי, מציגה אותו ומקריאה אותו בקול. היא פועלת בדפדפן, בלי התקנה ובלי שרת.

## מה היא יודעת לעשות
- **פתיחת ספר:** EPUB, PDF (שיש בו טקסט) ו־TXT, כולל קובצי טקסט בקידוד עברי ישן (Windows-1255). בוחרים קובץ או גוררים אותו לחלון.
- **הקראה בקול** בקולות שמותקנים במכשיר. היא בוחרת אוטומטית קול בעברית לספר בעברית, וקול באנגלית לספר באנגלית.
- **סימון המשפט שמוקרא** בצהוב וגלילה אוטומטית, כדי שהתלמיד יוכל לעקוב אחרי הטקסט בעיניים.
- לחיצה על משפט מתחילה את ההקראה ממנו. יש כפתורים למשפט קודם ולמשפט הבא, ומעבר בין פרקים.
- שליטה במהירות ההקראה, בגודל הגופן ובמצב כהה.
- **שמירת המקום:** כשפותחים שוב את אותו קובץ באותו מכשיר, ממשיכים מאותו משפט.
- מקלדת: רווח = הקראה/השהיה, חצים למעלה/למטה = משפט קודם/הבא.

## הגבלות
- הקובץ נקרא בתוך הדפדפן בלבד ואינו נשלח לשום מקום.
- **PDF סרוק** (תמונה של דף) אי אפשר להקריא, כי אין בו טקסט.
- פתיחת PDF דורשת חיבור לאינטרנט, כי רכיב ה־PDF (pdf.js) נטען מ־cdnjs. EPUB ו־TXT עובדים גם בלי אינטרנט.
- **ספרים מוגנים (DRM)**, כמו ספרים שנקנו ב־Kindle, בסטימצקי או בעברית, אי אפשר לפתוח. מתאים לספרים חופשיים (למשל מפרויקט בן־יהודה) ולחומרים שהמורה כתב/ה.
- איכות הקול תלויה במכשיר. אם לא מופיע קול בעברית:
  - **Windows:** הגדרות ← זמן ושפה ← דיבור ← הוספת קולות ← עברית.
  - **Android:** הגדרות ← נגישות ← המרת טקסט לדיבור ← מנוע Google ← התקנת עברית.
  - **Chromebook / Chrome:** קולות Google בעברית זמינים בדרך כלל כשיש אינטרנט.
