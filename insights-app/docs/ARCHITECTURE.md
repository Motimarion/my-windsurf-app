# ארכיטקטורה

## טכנולוגיות

| רכיב | בחירה | נימוק |
|---|---|---|
| ממשק | React 19 + TypeScript (strict) + Vite 6 | קוד אמיתי עם בדיקת טיפוסים, תצוגה מקדימה מיידית |
| ניתוב | Hash router ידני (`src/router.ts`) | כפתור "אחורה" עובד; לא דורש הגדרות שרת |
| אחסון | IndexedDB (`src/storage/db.ts`) | תומך ב־Blob של תמונות; נשאר במכשיר |
| תרשימים | SVG/CSS ידני (`src/components/charts.tsx`) | בלי ספריות; עובד ב־RTL וב־PDF |
| PDF | html2canvas + jsPDF (טעינה עצלה) | הדפדפן מצייר את העברית — אין היפוך אותיות |
| בדיקות | Vitest (יחידה), Playwright (קצה־לקצה) | |

## שש השכבות

```
תמונה ──► [א׳ ראייה מקומית] ──► QualityReport + ComputedFeatures ──► Observation(source=computed)
                                   סימון ידני מרשימה סגורה ─────────► Observation(source=manual)
Observation ──► [ג׳ מסורות] ──► TraditionNote ──claimId──► [ב׳ מאגר מחקר] ResearchClaim(level C/D)
תשובות ──► [ד׳ שאלונים] ──► ScaleScore[] , Holland code
ScaleScore[] ──► [ה׳ אינטגרציה] ──► IntegrationNote(claimId=integ_bf_riasec) + ReflectionPrompt
הכל ──► [ו׳ בקרת איכות] ──► QACheck[] ──► Report
```

**כלל ברזל מבני:** `scoreScales()` מקבלת רק תשובות לשאלונים. אין נתיב קוד מתמונה לציון.
בדיקת QA מס׳ 5 מחשבת מחדש את הציונים מהתשובות ומשווה לדוח, ובדיקת יחידה מוודאת שהציונים זהים עם תמונות ובלעדיהן.

## מודל הנתונים (`src/types.ts`)

- `Session` — מזהה, כינוי (לא שם), דגל `isDemo`, רשומת הסכמה (גרסה + זמן), תשובות `ipip`/`riasec`, תצפיות לכל ערוץ, `analyzedAt`.
- `ImageRecord` — תמונה אחת לכל ערוץ (תמונה חדשה מחליפה את הקודמת), `QualityReport`, `ComputedFeatures`.
- `Observation` — `{featureId, value, source}`; `value` חייב להיות מתוך `options` של המאפיין (נבדק ב־QA).
- `ResearchClaim` — טענה + רמה A–D + מקורות. `Source.verification` = `verified-db` | `pending`.
- `TraditionNote` — טקסט בניסוח "נטען ש..." + `claimId` חובה (מקושר רק לטענות C/D).
- `Report` — נגזר תמיד מחדש מ־Session + מטא־דאטה של תמונות (פונקציה טהורה, ניתנת לשחזור).

## סולם הראיות

| רמה | משמעות |
|---|---|
| A | ראיות עקביות ומשוכפלות (מטא־אנליזות / תיקוף פסיכומטרי) |
| B | ראיות חלקיות, מעורבות או אפקטים קטנים |
| C | נחקר — והמחקר אינו תומך בטענה |
| D | אין מחקר אמפירי ידוע; מסורת או טענה בלבד |

> הסולם הוגדר בגרסה זו. אם במסמכי המחקר המקוריים (r3–r6) יש סולם אחר — יש למפות אליו ולתעד ב־DECISIONS.md.

## שכבה א׳ — מה החישוב המקומי עושה בפועל

- **איכות:** רזולוציה (צד קצר ≥600), בהירות ממוצעת, ניגודיות (סטיית תקן), חדות (שונות לפלסיאן על תמונה מוקטנת ל־800px).
  הספים שונים לצילום כף יד (`photo`) ולדף (`page`) — דף לבן עם מעט דיו הוא תקין.
- **דף (כתב יד/ציור):** סף Otsu (מוגבל ל־170), שוליים של 3% מוחרגים, מסגרת תוחמת לפי אחוזונים 1–99,
  מרכז כובד → "גודל" ו"מיקום"; פרופיל הקרנה אופקי → מספר שורות (פערים עד 1.2% מגובה הדף מאוחדים).
- **מה הוא לא עושה:** אינו מזהה קווי כף יד, נטיית אותיות, לחץ עט או תוכן הציור. אלה מסומנים ידנית.

## ספקי AI (`src/engine/providers.ts`)

ממשק `VisionProvider` עם `status` ו־`sendsDataOffDevice`. Claude ו־Gemini רשומים כ־`inactive`.
