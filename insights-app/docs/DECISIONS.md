# יומן החלטות

## הקשר: מי עבד על מה

המשימה המקורית הגדירה עבודה בשלושה מודלים (ChatGPT — ניהול, Claude — פיתוח, Gemini — ביקורת).
לפי הנחיית "שדרוג: Claude Code בלבד", כל העבודה בוצעה ב־Claude Code:

| תפקיד | בפועל |
|---|---|
| ארכיטקטורה ופיתוח | Claude Code (הסשן הראשי) |
| ביקורת עצמאית (במקום Gemini) | סוכן־משנה של Claude Code, בהקשר נקי, ללא הרשאת עריכה — **אותה משפחת מודלים, לכן אינו ביקורת "חיצונית" באמת** |
| אימות מקורות | חיפוש במאגר האקדמי Consensus |
| ChatGPT / Gemini | **לא הופעלו.** לא התקבלה מהם שום תגובה, ואין לטעון ששיתפו פעולה |

**לא היו נגישים:** ה־Space ב־ChatGPT ועמוד הידע (דורשים התחברות שאינה זמינה מסביבה זו),
ומחקרי המקור r3–r6 וקובצי "Deep Research report(1–3)" — חיפוש ב־Google Drive לא איתר אותם.
לכן ההחלטות שלהלן **לא הושוו** למפרט ולדירוגי הראיות שב־Space. זו משימה פתוחה (ראו STATUS.md).

## החלטות בעקבות הביקורת העצמאית (12 ממצאים)

| ממצא | החלטה |

| סימונים ידניים נשארים אחרי החלפת תמונה | **תוקן**: החלפה מאפסת סימונים ידניים, עם הודעה למשתמש (נבדק ב־e2e) |

| השוואת ממוצעים גולמיים בין תכונות ("הציון הגבוה ביותר") | **תוקן**: השאלה מתייחסת לתכונה שבקצה הסולם שלה, בלי השוואה בין תכונות |
| הערת "תמונות לא בציונים" ציטטה תמיד את מחקר הציורים | **תוקן**: הערה וטענה לפי סוג הערוץ; כף יד = "לא נחקר", ולא "נמצא לא תקף" |
| שאלת "פרשנויות מסורתיות" מוצגת גם בלי תמונות | **תוקן** |
| ציטוטים: Baldasaro 2012→**2013, 95(1), 74–84**; Koch 1952→**1949** (1952 = תרגום אנגלי) | **תוקן**. Taylor 2015: הרשומה קיימת במאגר; פרטי המחברים מסומנים לאימות |
| טענות ברמה A שנשענות רק על מקורות לא מאומתים | **תוקן**: Barrick 2003 ו־Armstrong 2008 **אומתו במאגר**; נוספה בדיקת QA וגם בדיקת יחידה שדורשות מקור מאומת לכל טענה ברמה A |
| מחיקה במקביל להעלאה עלולה להשאיר תמונה יתומה | **תוקן**: מחיקה דרך סמן באותה טרנזקציה; `putImage` נכשל אם התהליך נמחק |
| EXIF (מיקום GPS) נשמר עם התמונה | **תוקן**: נשמר רק עותק מקודד מחדש (≤2000px) ללא מטא־נתונים (נבדק ב־e2e) |
| Google Fonts שולח IP לגוגל | **תוקן**: הגופן מוגש מהאפליקציה; e2e מוודא אפס בקשות לשרתים חיצוניים |
| נגישות: כפתורי העלאה לא נגישים במקלדת, רדיו בלי חיצים, חלון בלי מלכודת פוקוס, HEIC | **תוקן**: קלט מוסתר ויזואלית בלבד (sr-only), חיצים ו־roving tabindex, מלכודת פוקוס ו־aria-labelledby, HEIC הוסר ומוצגת הנחיה לאייפון |

## שינוי דירוג ראיות — עם מקור ונימוק

- **`integ_bf_riasec`: A → B.** בחיפוש לאימות Barrick et al. (2003) נמצאה גם המטא־אנליזה הרב־משתנית
  Hurtado Rúa et al. (2018, *Journal of Career Assessment*; 34 מחקרים, N=19,872): אומדנים בין −.08 ל־.36,
  עם תלות בכלי המדידה ובמדינה. המסקנה המשותפת — קשר קיים אך מתון ואינו אחיד — מתאימה יותר לרמה B.
  הדירוג הוגדר בגרסה זו; הוא לא שינה דירוג קיים מה־Space (שלא היה נגיש).
