# דוח תובנות משולב — MVP

אפליקציית Web בעברית (RTL), למחשב ולנייד, שמשלבת חמישה מקורות מידע לדוח אחד:
צילומי כפות ידיים, כתב יד בעברית, ציור עץ וציור אדם, שאלון Big Five (Mini-IPIP) ושאלון RIASEC.

**העיקרון המנחה:** הפרדה מוחלטת בין שלושה סוגי מידע:

| סוג | מקור | האם משפיע על ציונים? |
|---|---|---|
| **מה נמדד** | תשובות לשאלונים | כן — זה המקור היחיד לציונים |
| **מה נצפה** | מאפיינים שרואים בתמונה (חישוב אוטומטי + סימון ידני מרשימה סגורה) | לא |
| **מה נטען במסורת** | כירומנטיה, גרפולוגיה, ציורים השלכתיים — עם דירוג ראיות לצידן | לא |

> כלי למחקר ולהדגמה עם בגירים שהסכימו להשתתף. אינו כלי אבחון ואין להשתמש בו להחלטות על אנשים.

## הרצה

```bash
cd insights-app
npm install
npm run dev        # שרת פיתוח: http://localhost:5173
npm test           # 40 בדיקות יחידה (Vitest)
npm run build      # בנייה לייצור → dist/
npm run e2e        # 37 בדיקות קצה־לקצה (Playwright; דורש build קודם)
```

אין צורך במפתחות API, בשרת או במסד נתונים. כל הנתונים נשמרים ב־IndexedDB בדפדפן.

## מבנה

```
src/
  types.ts               מודל הנתונים (מתויג לפי שכבות א׳–ו׳)
  data/
    questionnaires.ts    Mini-IPIP (20) + RIASEC (30) — נוסחים, מפתח ניקוד
    evidence.ts          שכבה ב׳: מקורות, טענות, רמות ראיות A–D
    channels.ts          הוראות צילום, מאפיינים לתצפית, שכבה ג׳: פרשנויות מסורתיות
    consent.ts           טופס הסכמה מדעת (גרסה)
  engine/
    imageAnalysis.ts     שכבה א׳: איכות תמונה, Otsu, מסגרת תוחמת, ספירת שורות
    providers.ts         ממשק לספקי ראייה (Claude/Gemini — מוצגים כלא פעילים)
    scoring.ts           שכבה ד׳: ניקוד, ניקוד הפוך, קוד Holland
    report.ts            שכבות ה׳+ו׳: אינטגרציה, נקודות להתבוננות, 9 בדיקות QA
    ingest.ts            העלאה → ניתוח מקומי → שמירה
  storage/db.ts          IndexedDB: תהליכים ותמונות, מחיקה מלאה
  demo/synthetic.ts      משתמש סינתטי, תמונות שנוצרות ב־Canvas, תשובות דטרמיניסטיות
  report/pdf.ts          ייצוא PDF (html2canvas + jsPDF) עם חיתוך עמודים בגבולות כרטיסים
  screens/               בית, הסכמה, סקירה, ערוץ תמונה, שאלון, ניתוח, דוח, אודות
e2e/run.mjs              תרחישי Playwright: מחשב, iPhone 13, Pixel 7
docs/                    ארכיטקטורה, החלטות, בדיקות, סטטוס ותוכנית המשך
```

ראו [`docs/STATUS.md`](docs/STATUS.md) למה עובד, מה מדומה ומה נדרש לגרסת ייצור.
