# הגדרת חיבור ל־Claude ול־Google Sheets

אחרי ההגדרה הזו (פעם אחת, בערך 15 דקות):
- **התלמידים** עובדים מקישור בלבד: בלי חשבון, בלי התקנה ובלי סיסמה.
- **Claude** בודק את התשובות הפתוחות לפי המשמעות, עם מפתח ה־API שלכם. התלמידים לא רואים את המפתח.
- **כל ניסיון של כל תלמיד** נשמר אוטומטית בגיליון Google Sheets שלכם.

---

## שלב 1: מפתח API של Anthropic (בערך 5 דקות)

מפתח API הוא חשבון נפרד מהמנוי ל־claude.ai: משלמים לפי שימוש.

1. נכנסים ל־**console.anthropic.com** ונרשמים (או מתחברים).
2. **מוסיפים יתרה:** Settings ← Billing. מספיקים כמה דולרים להתחלה.
3. **מגבילים הוצאה (מומלץ מאוד):** Settings ← Limits ← מגדירים תקרה חודשית, למשל 10 דולר.
4. **יוצרים מפתח:** API Keys ← Create Key ← נותנים שם (למשל ״מורה אישי במדעים״) ← מעתיקים את המפתח. הוא מתחיל ב־`sk-ant-`.

> ⚠️ המפתח הוא כמו סיסמה. לא שולחים אותו לאף אחד, ולא מדביקים אותו בשום מקום חוץ מהשלב הבא.

**עלות משוערת:** בדיקה אחת עם Claude Haiku 5.5 עולה בערך עשירית סנט. כיתה של 30 תלמידים שעונה על כל השאלות הפתוחות עולה, לפי הערכה, פחות מדולר אחד. זו הערכה, לא מדידה, אז כדאי לבדוק את ההוצאה בפועל ב־Console אחרי השיעור הראשון.

## שלב 2: גיליון וסקריפט (בערך 5 דקות)

1. ב־Google Drive יוצרים **גיליון חדש**. אפשר לקרוא לו ״מורה אישי במדעים – תשובות״.
2. בתפריט של הגיליון: **הרחבות (Extensions) ← Apps Script**.
3. מוחקים את כל מה שכתוב בעורך, ומדביקים את כל התוכן של הקובץ **`Code.gs`** שנמצא באותה תיקייה עם הקובץ הזה.
4. לוחצים על **💾 שמירה**.

## שלב 3: הגדרת המפתח וקוד הכיתה

1. בעורך של Apps Script, בתפריט שבצד שמאל, לוחצים על **⚙️ Project Settings**.
2. גוללים למטה עד **Script Properties**, לוחצים **Add script property** ומוסיפים שתי שורות:

| Property | Value |
|---|---|
| `ANTHROPIC_API_KEY` | המפתח משלב 1 (מתחיל ב־`sk-ant-`) |
| `CLASS_KEY` | קוד כיתה שאתם ממציאים, בלי רווחים. למשל: `madaim-4b-2026` |

3. **לא חובה:** אפשר להוסיף `DAILY_LIMIT` עם מספר הבדיקות המרבי ביום. ברירת המחדל היא 3000.
4. לוחצים **Save script properties**.

## שלב 4: פריסה כאפליקציית רשת

1. למעלה מימין: **Deploy ← New deployment**.
2. ליד ״Select type״ לוחצים על ⚙️ ובוחרים **Web app**.
3. ממלאים:
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`
4. לוחצים **Deploy**.
5. Google יבקש אישור הרשאות. לוחצים **Authorize access**, ובוחרים את החשבון שלכם.
   - אם מופיעה האזהרה **״Google hasn't verified this app״**: לוחצים **Advanced** ואז **Go to … (unsafe)**. זה הסקריפט שלכם, והאזהרה מופיעה לכל סקריפט פרטי.
6. מעתיקים את **Web app URL**. הכתובת מתחילה ב־`https://script.google.com/macros/s/` ונגמרת ב־`/exec`.

## שלב 5: חיבור האפליקציה ושליחת קישור לתלמידים

1. פותחים את האפליקציה: `https://motimarion.github.io/my-windsurf-app/science-tutor/`
2. נכנסים ל**מסך מורה ← ייבוא, ייצוא והגדרות**.
3. בכרטיס **״חיבור ל־Claude ול־Google Sheets״** מדביקים:
   - את **כתובת השרת** משלב 4;
   - את **קוד הכיתה** (`CLASS_KEY`) משלב 3.
4. לוחצים **שמירה ובדיקת חיבור**. צריכה להופיע ההודעה: ״✓ החיבור עובד״.
5. מופיע **הקישור לתלמידים**. לוחצים **העתקת הקישור** ושולחים אותו לתלמידים, למשל ב־Google Classroom.

כשתלמיד פותח את הקישור, המכשיר שלו נשמר כמחובר לשרת, ואפשר לעבוד מיד.

---

## איך זה עובד מאחורי הקלעים

- **תשובה פתוחה:** האפליקציה שולחת לסקריפט שלכם את השאלה, את רכיבי המחוון ואת תשובת התלמיד. הסקריפט מוסיף את המפתח, שולח ל־Claude ומחזיר החלטה: נכון / חלקי / שגוי / לא ודאי, עם רמז ונימוק.
- **פרטיות:** הקוד האישי של התלמיד לא נשלח ל־Claude. הוא נשמר רק בגיליון שלכם.
- **שמירה:** כל ניסיון נשלח לגיליון ״ניסיונות״, בלשונית חדשה שנוצרת אוטומטית. אם אין אינטרנט, הניסיון מחכה במכשיר ונשלח בהמשך.
- **בלי חיבור לשרת:** אם השרת לא זמין, האפליקציה בודקת לפי מילים, ותשובה בניסוח חופשי עדיין מתקבלת ונשלחת לבדיקת מורה.

## הגנות

- בלי קוד הכיתה הנכון, הסקריפט לא שולח שום דבר ל־Claude.
- **מגבלות שימוש:** עד 20 בדיקות בדקה לכל תלמיד, ועד `DAILY_LIMIT` בדיקות ביום לכל הכיתה.
- הסקריפט מסוגל רק לבדוק תשובות, ולא משמש לשימוש כללי ב־Claude.
- **תקרת הוצאה:** התקרה החודשית שהגדרתם ב־Console היא ההגנה האחרונה.
- **אם הקישור הגיע למי שלא צריך:** משנים את `CLASS_KEY` ב־Script Properties, ושולחים לתלמידים קישור חדש.

## עדכון הסקריפט בעתיד

1. מדביקים את הקוד החדש ושומרים.
2. **Deploy ← Manage deployments ← ✏️ (עריכה) ← Version: New version ← Deploy**.

כך הכתובת נשארת אותה כתובת, ואין צורך לשלוח קישור חדש.

## פתרון תקלות

| מה רואים | מה לעשות |
|---|---|
| ״קוד הכיתה לא תואם״ | בדקו שהקוד בשדה זהה בדיוק ל־`CLASS_KEY`, כולל אותיות גדולות וקטנות. |
| ״אין חיבור לשרת״ | בדקו שהכתובת נגמרת ב־`/exec`, ושבפריסה נבחר `Who has access: Anyone`. |
| ״לא הוגדר ANTHROPIC_API_KEY״ | הוסיפו את המפתח ב־Script Properties (שלב 3). |
| התשובות נבדקות לפי מילים ולא בעזרת Claude | בדקו שיש יתרה ב־Console, ושלא עברתם את `DAILY_LIMIT`. |
